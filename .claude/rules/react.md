# React 规则

## 组件结构

- **函数组件**：优先使用函数组件而非类组件
- **小巧专注**：保持组件小巧且专注
- **自定义 hook**：将可复用逻辑提取到自定义 hook 中
- **组合优于继承**：使用组合而非继承
- **类型安全**：使用 TypeScript 实现适当的 prop 类型
- **适当拆分**：将大型组件拆分为更小、更专注的组件
- **组件库优先**：优先使用 antd 中的组件

## Hooks

- **遵循规则**：遵循 Hooks 的规则
- **复用逻辑**：使用自定义 hooks 实现可复用逻辑
- **专注简单**：保持 hooks 专注且简单
- **依赖数组**：在 useEffect 中使用适当的依赖数组
- **清理功能**：在需要时在 useEffect 中实现清理功能
- **避免嵌套**：避免嵌套 hooks
- **禁止缓存钩子**：禁止使用 useCallback、useMemo

## 状态管理

- **本地状态**：使用 useState 管理组件本地状态
- **复杂状态**：使用 useReducer 处理复杂状态逻辑
- **共享状态**：使用 Context API 共享状态
- **就近管理**：将状态尽可能靠近使用它的地方
- **避免 prop drilling**：通过适当的状态管理避免 prop drilling
- **按需引入**：仅在必要时使用状态管理库（mobx）

## 性能

- **Memo 优化**：对开销大的组件使用 React.memo
- **减少渲染**：避免不必要的重新渲染
- **懒加载**：实现适当的懒加载
- **列表 key**：在列表中使用适当的 key 属性
- **性能分析**：分析并优化渲染性能

## 表单

- **受控组件**：对表单输入使用受控组件
- **表单验证**：实现适当的表单验证
- **提交状态**：正确处理表单提交状态
- **加载与错误**：显示适当的加载和错误状态
- **复杂表单**：对复杂表单使用表单库
- **可访问性**：为表单实现适当的可访问性

## 错误处理

- **Error Boundaries**：实现 Error Boundaries
- **异步错误**：正确处理异步错误
- **友好提示**：显示用户友好的错误信息
- **备用 UI**：实现适当的备用 UI
- **错误记录**：适当记录错误
- **边缘情况**：优雅处理边缘情况

## 测试

- **单元测试**：为组件编写单元测试
- **集成测试**：为复杂流程实现集成测试
- **测试库**：使用 React Testing Library
- **交互测试**：测试用户交互
- **错误场景**：测试错误场景
- **模拟数据**：实现适当的模拟数据

## 可访问性

- **语义化 HTML**：使用语义化 HTML 元素
- **ARIA 属性**：实现适当的 ARIA 属性
- **键盘导航**：确保键盘导航

## 代码组织

- **命名约定**：使用适当的文件命名约定
